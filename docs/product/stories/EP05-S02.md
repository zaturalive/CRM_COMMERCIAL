# EP05-S02 — Devis technique (UI partie technique)

> **HDS-CHECK** (2026-05-20) — Verdict : `OK avec rename`
> Periode : NON-HDS (cf. ADR-0008 du repo source + ADR-0002 du repo commercial)
> Reformulation appliquee : "focusser sur l'acte medical" -> "focusser sur la partie technique de la prestation". Le titre "UI chirurgien" devient "UI partie technique".
> ADR-0002 : le role CHIRURGIEN est retire. La partie technique est saisissable par tous les roles (COMMERCIAL + ADMIN). Le role-gating sur les champs `cliniqueId`/`dateIntervention`/`timeIntervention` est retire.
> Mots-cles SUSPECT restants : "intervention" (preferer "prestation"), "devis" est commercial donc OK.

**Epic** : Devis • **Priorite** : Must have • **Estimation** : 3h

## User story

En tant que **utilisateur** (COMMERCIAL ou ADMIN), je veux **remplir la partie technique du devis** (prestations + duree + frais supp) afin de **focusser sur la partie technique de la prestation** avant l'enrichissement commercial (clinique, date, heure).

## Acceptance Criteria

1. Section "Technique" du `<DevisBuilder />` avec border-left bleue 4px
2. Par prestation (repeatable) :
   - Dropdown prestation (depuis le catalogue)
   - Input duree (minutes)
   - Date picker (optional)
   - Prix honoraires (mono, display seulement — pas editable au niveau prestation)
   - Sous-liste `<FeeSubList />` : checkbox `isIncluded` + label editable + input prix mono + input qty mono + Lucide Trash2
   - Bouton `+ Ajouter un frais` (form inline)
3. Bouton `+ Ajouter prestation`
4. Sous-total honoraires visible (bold mono "Total honoraires : X €")
5. **Pas de dropdown clinique** (section commerciale apparait apres)
6. Auto-save debounced 500ms sur chaque modif
7. Endpoints :
   - `POST /api/processes/:id/devis/:devisId/devis-interventions` (ajouter)
   - `PATCH /api/devis-interventions/:id` (modifier)
   - `DELETE /api/devis-interventions/:id`
   - `POST/PATCH/DELETE /api/devis-interventions/:id/fees`

## Tests

- Test UI : modifier un frais → recalc total visible en temps reel
- Test API : PATCH avec interventionId valide → 200, re-snapshot priceHonoraires/duration
