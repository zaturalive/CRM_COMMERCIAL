# EP05-S02 — Devis technique (UI chirurgien)

**Epic** : Devis • **Priorite** : Must have • **Estimation** : 3h

## User story

En tant que **chirurgien**, je veux **remplir la partie technique du devis** (interventions + duree + frais supp) sans voir de clinique, afin de **focusser sur l'acte medical**.

## Acceptance Criteria

1. Section "Technique" du `<DevisBuilder />` avec border-left bleue 4px
2. Par intervention (repeatable) :
   - Dropdown intervention (depuis le catalogue)
   - Input duree (minutes)
   - Date picker (optional)
   - Prix honoraires (mono, display seulement — pas editable au niveau intervention)
   - Sous-liste `<FeeSubList />` : checkbox `isIncluded` + label editable + input prix mono + input qty mono + Lucide Trash2
   - Bouton `+ Ajouter un frais` (form inline)
3. Bouton `+ Ajouter intervention`
4. Sous-total honoraires visible (bold mono "Total honoraires : X €")
5. **Pas de dropdown clinique** (section commerciale apparait apres)
6. CHIR peut modifier les interventions posees par COMM (ajouter, supprimer, changer duree/prix ligne par ligne)
7. Auto-save debounced 500ms sur chaque modif
8. Endpoints :
   - `POST /api/processes/:id/devis/:devisId/devis-interventions` (ajouter)
   - `PATCH /api/devis-interventions/:id` (modifier, **sans** `cliniqueId`/`dateIntervention`/`timeIntervention` — refuses)
   - `DELETE /api/devis-interventions/:id`
   - `POST/PATCH/DELETE /api/devis-interventions/:id/fees`

## Tests

- Test securite : CHIR PATCH avec `cliniqueId` dans body → 403
- Test UI : modifier un frais → recalc total visible en temps reel

## Notes techniques

- Composants : `<TechniqueSection />`, `<FeeSubList />`, `<InterventionFeeRow />`
- Le chirurgien peut override le prix d'un frais supp specifique au devis
