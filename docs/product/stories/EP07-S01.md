## User story

En tant qu'**utilisateur** (COMMERCIAL ou ADMIN — ADR-0002 retire CHIRURGIEN), je veux **voir l'agenda avec toutes les consultations et operations** derives automatiquement depuis la pipeline, afin de **ne pas avoir a creer d'events manuellement**.

## Acceptance Criteria

1. Page `/agenda` accessible tous roles (ADMIN + COMMERCIAL — ADR-0002 retire CHIRURGIEN)
2. Vues : Jour / **Semaine** (defaut) / Mois
3. Toolbar :
   - Nav `< [Aujourd'hui] >` segmented
   - Periode affichee (ex "27 avril – 3 mai 2026")
   - Switch Jour/Semaine/Mois
4. Grille semaine :
   - 7 jours (Lun → Dim)
   - Time labels mono 11px gris, 7h → 20h, tranches 1h (hauteur 60px)
   - Jour courant : fond `linear-gradient(180deg, #F5F3FF 0%, #FFFFFF 100%)` + label "Aujourd'hui"
   - Ligne "now" : trait 2px `#EF4444` + pastille a l'heure actuelle
5. **Events derives** :
   - Consultations : `Process.consultationDate` (hors archives)
   - Operations : `DevisStay.date` des devis signes, 1 event par sejour
6. Duree event operation = somme des `DevisIntervention.duration` du sejour
7. `<EventBlock />` avec 7 variants selon statut paiement (cf. design spec §1.4)
8. Endpoint `GET /api/agenda?from=YYYY-MM-DD&to=YYYY-MM-DD` retourne les events projetes
9. Code couleur instantane :
   - Bleu : consult payee
   - Gris : consult non payee
   - Rouge : op sans acompte
   - Amber : op solde partiel
   - Emerald : op solde 100% prete
   - Grise barree : op effectuee
