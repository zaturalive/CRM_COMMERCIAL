# EP05-S03 — Devis commercial (3 cols clinique/date/heure)

**Epic** : Devis • **Priorite** : Must have • **Estimation** : 3h

## User story

En tant que **commercial**, je veux **renseigner la clinique, la date et l'heure de chaque intervention** afin de **finaliser le devis avec le prix total patient**.

## Acceptance Criteria

1. Section "Commerciale" du `<DevisBuilder />` avec border-left violette 4px
2. Par `DevisIntervention` — **3 colonnes** :
   - Col 1 : Dropdown Clinique (depuis catalogue)
   - Col 2 : Date picker
   - Col 3 : Time picker `<TimeInput />` (HH:MM, format 24h)
3. Au choix clinique : fetch `/api/cliniques/:id/options` → options catalogue s'affichent dans la section dediee (cf. EP05-S05)
4. Auto-calcul des frais clinique (bloc + anesthesie) selon la duree et la tranche de `CliniqueTarif`
5. Endpoint `PATCH /api/devis-interventions/:id` autorise `cliniqueId`, `dateIntervention`, `timeIntervention` pour COMMERCIAL
6. Chirurgien ne peut **pas** modifier ces 3 champs (403 si tente)
7. Apres modification clinique/date, hook `reconcileStays(devisId)` appele (cf. EP05-S04)
8. **Pre-remplissage auto** : si le process a deja des `ProcessIntervention` mais pas de devis, au clic "+ Nouveau devis" on cree le devis avec les interventions pre-chargees (cf. EP05-S01)

## Tests

- Test securite : COMM PATCH `timeIntervention = "09:30"` → 200
- Test securite : CHIR PATCH `cliniqueId` → 403
- Test : changer clinique → fetch options + reconcileStays appele

## Notes techniques

- `<TimeInput />` composant custom : input type time + formatage HH:MM
- Calcul frais clinique : trouver la `CliniqueTarif` ou `duration BETWEEN dureeMin AND dureeMax`
