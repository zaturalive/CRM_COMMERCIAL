## User story

En tant que **utilisateur** (COMMERCIAL ou ADMIN), je veux **ecrire une note commerciale sur un process** (contexte client, relances, budget, motivation), afin de **garder une trace lisible par tous les roles operationnels** du cabinet.

## Acceptance Criteria

1. Onglet "Notes" du Process Panel affiche 1 textarea "Note commerciale".
2. Auto-save debounced 2s apres la derniere frappe (toast d'erreur si echec).
3. Route backend `PATCH /api/processes/:id/notes` accepte `{ noteCommerciale: string | null }`.
4. GET process renvoie `noteCommerciale` dans le JSON pour tous les roles authentifies.
5. Pas de role-gating au niveau de l'ecriture (COMMERCIAL et ADMIN peuvent ecrire).

## Tests

- Test API : `PATCH /api/processes/:id/notes` par COMMERCIAL → 200, valeur persistee.
- Test API : `PATCH /api/processes/:id/notes` par ADMIN → 200, valeur ecrasee.
- Test API : `PATCH /api/processes/:id/notes` sans `noteCommerciale` dans le body → 400 (Zod).
- Test API : GET process → JSON contient `noteCommerciale`.
