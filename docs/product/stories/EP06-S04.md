# EP06-S04 — Preview Agent IA mock WhatsApp interactif

**Epic** : Documents • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **utilisateur (demo)**, je veux **voir un mock WhatsApp en bas de l'onglet Documents** avec zone de saisie interactive, afin de **comprendre ce que fera l'Agent IA en V1**.

## Acceptance Criteria

1. Composant `<AIAgentWhatsAppPreview />` en bas de l'onglet Documents du Process Panel
2. Conteneur ~400×480px, **opacity 0.75** (grise)
3. Badge "V1 — Apercu" en coin (Lucide Sparkles + fond violet pale)
4. Header WhatsApp-style :
   - Avatar bot (Lucide Bot)
   - Nom "Agent IA — Secretaire virtuelle"
5. Zone messages, fond gradient pale `#E5DDD5` translucide :
   - Bulles bot (blanc, gauche) avec radius 12 + ombre
   - Bulles patient (`#DCF8C6`, droite) avec radius 12
6. Messages mock pre-remplis (3-4 echanges) :
   - Bot : "Bonjour Marie, je suis l'assistante virtuelle du Dr Delobaux..."
   - Bot : "Pourriez-vous m'envoyer votre bilan sanguin en photo ?"
   - Patient : "Bien sur, je fais ca ce soir"
   - Bot : "Parfait, je vous rappelle aussi votre consentement eclaire a signer."
7. **Zone de saisie interactive** en bas :
   - `<textarea>` + bouton Lucide Send (accent)
   - Enter = envoyer
   - Saisie → ajoute bulle patient (droite)
   - Bot repond avec un message mock determinist (lookup dans un dict)
8. Mention : "Connexion API WhatsApp Business Cloud prevue en V1"

## Tests

- Test interaction : saisir "bilan fait" + envoyer → bulle patient + reponse bot mock
- Test visuel : opacity 0.75 + badge V1 visible

## Notes techniques

- State local (useState) — pas persiste en BDD
- Dict reponses : 5-10 patterns mock (match par keyword)
- En V1 : remplacer par connexion WebSocket a l'API WhatsApp + Claude API
