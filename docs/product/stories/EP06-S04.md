> **HDS-CHECK** (2026-05-20) — Verdict : `OK avec rename`

> Reformulation appliquee : les messages mock ne referencent plus aucun document medical (bilan, consentement eclaire). Remplacement par des echanges commerciaux (devis, RIB, RDV, carte d'identite). Nom "Dr Delobaux" remplace par "cabinet".
> Mots-cles SUSPECT restants : "patient" (preferer "client"), gere en P4 Sprint vocabulaire.

**Epic** : Documents • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **utilisateur (demo)**, je veux **voir un mock WhatsApp en bas de l'onglet Documents** avec zone de saisie interactive, afin de **comprendre ce que fera l'Agent IA en V1**.

## Acceptance Criteria

1. Composant `<AIAgentWhatsAppPreview />` en bas de l'onglet Documents du Process Panel
2. Conteneur ~400×480px, **opacity 0.75** (grise)
3. Badge "V1 — Apercu" en coin (Lucide Sparkles + fond violet pale)
4. Header WhatsApp-style :
   - Avatar bot (Lucide Bot)
   - Nom "Agent IA — Secretaire virtuelle"
5. Zone messages, fond gradient pale `#E5DDD5` translucide :
   - Bulles bot (blanc, gauche) avec radius 12 + ombre
   - Bulles client (`#DCF8C6`, droite) avec radius 12
6. Messages mock pre-remplis (4-5 echanges, contenu commercial uniquement) :
   - Bot : "Bonjour Marie, je suis l'assistante virtuelle du cabinet. Votre devis est pret a signer."
   - Client : "Super, je peux y jeter un oeil quand ?"
   - Bot : "Vous pouvez le consulter via le lien que je viens de vous envoyer. Pouvez-vous m'envoyer votre RIB pour planifier l'acompte ?"
   - Client : "Bien sur, je fais ca ce soir."
   - Bot : "Parfait. Merci aussi d'envoyer votre carte d'identite pour finaliser le dossier. Le RDV de pre-prestation est confirme pour le 12 juin."
7. **Zone de saisie interactive** en bas :
   - `<textarea>` + bouton Lucide Send (accent)
   - Enter = envoyer
   - Saisie → ajoute bulle client (droite)
   - Bot repond avec un message mock determinist (lookup dans un dict)
8. Mention : "Connexion API WhatsApp Business Cloud prevue en V1"

## Tests
