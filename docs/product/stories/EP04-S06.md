# EP04-S06 — Archivage automatique des process effectues

> **HDS-CHECK** (2026-05-18) — Verdict : `OK avec rename`
> Periode : NON-HDS (cf. ADR-0008 du repo source)
> Mots-cles BLOCKED detectes : aucun
> Mots-cles SUSPECT detectes : "intervention" (preferer "prestation")
> Action : rename requis
> Justification : hook backend de bascule isArchived=true selon paiement et cochage. Logique purement metier commercial.

**Epic** : Pipeline & Process • **Priorite** : Should have • **Estimation** : 1.5h

## User story

En tant que **commercial**, je veux **que les process effectues disparaissent automatiquement de la pipeline** afin de **garder une vue lisible des affaires en cours**.

## Acceptance Criteria

1. Hook backend `checkAutoArchive(processId)` appele apres `PATCH /api/devis-interventions/:id/done`
2. Conditions d'archivage :
   - Toutes les `DevisIntervention` du process ont `isDone = true`
   - Solde paye >= total du devis (`soldePaidAmount + acompte >= totalCached`)
3. Si conditions remplies :
   - `Process.stage = EFFECTUEE`
   - `Process.isArchived = true`
   - `Process.archivedAt = now()`
4. `GET /api/pipeline` **exclut** les process archives (filter `isArchived = false`)
5. Les process archives restent visibles dans l'historique Fiche Client (EP03-S02)
6. Toast UI : "Process archive en Effectuee" apres la coche de la derniere intervention
7. Dashboard CA mis a jour (le CA de ce devis passe en "Confirme realise")

## Tests

- Test unit : `checkAutoArchive` avec toutes cochees + solde 100% → archivage
- Test unit : `checkAutoArchive` avec une intervention non cochee → pas d'archivage
- Test integration : API cocher derniere → process archive + pipeline sans ce process
