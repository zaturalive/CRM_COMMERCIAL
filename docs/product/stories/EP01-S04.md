# EP01-S04 — CopyButton transversal

**Epic** : Foundation • **Priorite** : Should have • **Estimation** : 1h

## User story

En tant que **commercial**, je veux **copier n'importe quel champ utile en un clic** afin d'**envoyer rapidement les infos au patient par SMS / mail / WhatsApp**.

## Acceptance Criteria

1. Composant `<CopyButton value={string} label?={string} size?={number} />`
2. Icone Lucide Copy (gris 45% opacity), hover → 100% opacity
3. Clic → `navigator.clipboard.writeText(value)` + toast "Copie !" 2 secondes
4. Apres clic : icone devient Check emerald pendant 2 secondes
5. Integrations transversales :
   - Fiche Client : nom, prenom, telephone, email, ville
   - Pipeline : nom patient + montant sur chaque carte
   - Devis : reference, nom interventions, prix, sous-totaux, total general
   - Parametrage : noms + prix interventions, labels + prix frais supp
   - Process Panel : reference process
6. Bouton special "Copier le devis complet en texte" (dans le header devis) :
   - Format multi-lignes avec interventions, frais, sejour, options, total
   - Template GET `/api/devis/:id/as-text`

## Notes techniques

- `navigator.clipboard` requiert HTTPS ou localhost — fallback sur `document.execCommand('copy')` en dev
- Le bouton est `size=14px` par defaut, mais 16px dans le devis et 12px dans les cartes pipeline
