# EP01-S02 — Design system liquid glass + CSS vars

**Epic** : Foundation • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **dev solo**, je veux **un design system centralise via CSS variables + Tailwind** afin de **tweaker les couleurs en live sans reedit massif des composants**.

## Acceptance Criteria

1. `src/styles/globals.css` contient les CSS vars de `spec-design-figma-v1_3.md` §1.7 (accent, sidebar, surface-glass, etc.)
2. `tailwind.config.ts` mappe les CSS vars vers les utilities (`bg-accent`, `text-danger`, `rounded-md`, etc.)
3. Composant `<GlassCard />` reutilisable avec backdrop-blur 20px + border rgba
4. Fond page : degrade lavande (`var(--page-bg)`) applique sur `/(app)/layout.tsx`
5. Sidebar opaque navy `var(--sidebar-bg)` (pas de glass)
6. Typo : DM Sans (titres) + Inter (corps) + JetBrains Mono (chiffres/heures/prix) charges via next/font
7. Pas de couleur hardcodee en dur dans les composants — verification via grep
8. Icones Lucide installees (`lucide-react`)
9. Composant `<CopyButton />` avec toast (sera affine en S04)

## Tests

- Test grep : `git grep -E "#[0-9a-fA-F]{6}" src/components | grep -v "globals.css"` → resultat vide
- Preview manuelle : changer `--accent` en `#FF5555` dans globals.css → les boutons changent de couleur sans rebuild
