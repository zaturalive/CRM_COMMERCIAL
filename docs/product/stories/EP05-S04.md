# EP05-S04 — Sejours + mode hospitalisation + reconcileStays

**Epic** : Devis • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **commercial**, je veux **voir un sejour auto-genere pour chaque couple (clinique, date) du devis** avec toggle ambulatoire/nuit(s), afin de **choisir le mode d'hospitalisation et calculer le prix en fonction**.

## Acceptance Criteria

1. Section "Sejour(s)" sous la section commerciale
2. **1 `<DevisStayCard />` par couple unique (clinique, date)** des `DevisIntervention`
3. Chaque card :
   - Header : "Sejour du [date] a [clinique]" (DM Sans 16px)
   - Toggle segmente : `Ambulatoire | Nuit(s)` (defaut AMBULATOIRE)
   - Si NUIT : `<NightCountStepper />` (boutons − / +, min 1, max 30)
   - Cout a droite (mono, calcul live)
4. Hook backend `reconcileStays(devisId)` :
   - Apres PATCH `devis-intervention` avec nouveaux `cliniqueId`/`dateIntervention` :
     - Lister couples uniques des DevisIntervention
     - Creer les manquants dans `DevisStay` (mode AMBU, nightCount 1)
     - Supprimer les DevisStay orphelins
5. Endpoint `PATCH /api/devis-stays/:id` pour modif `mode` et `nightCount`
6. Validation : si `mode = NUIT`, `nightCount >= 1 AND <= 30`
7. Transaction atomique pour toute modification

## Tests

- Test unit : `reconcileStays` idempotent (2 appels → meme resultat)
- Test unit : couple supprime (derniere intervention changee) → DevisStay supprime
- Test securite : COMM seul peut modifier mode/nightCount (CHIR 403)
