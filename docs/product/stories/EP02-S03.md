# EP02-S03 — CRUD Interventions catalogue

**Epic** : Parametrage Admin • **Priorite** : Must have • **Estimation** : 2h

> **Note 23/04** : le Parametrage est ouvert a tous les roles (plus ADMIN only). Voir [ADR-0006](../../architecture/decisions/0006-config-open-to-all-roles.md). Les mentions "ADMIN only / exclusif" dans cette story sont **revertes**.

## User story

En tant que **admin**, je veux **maintenir le catalogue des interventions chirurgicales et esthetiques** afin que **les devis soient pre-remplis avec les bons prix d'honoraires**.

## Acceptance Criteria

1. Page `/config/interventions` accessible ADMIN
2. Liste filtrable (nom, categorie, duree, prix, marge, actif)
3. Form edition (modal ou page) : nom, categorie (CHIRURGIE/MED_ESTH/SOIN), duree (minutes), priceHonoraires (centimes), marginCoeff, isActive
4. Sous-sections "Frais supplementaires" et "Documents a demander" — voir EP02-S04 et EP02-S05
5. Toggle `isActive` : les interventions inactives ne s'affichent pas dans le cochage patient
6. Suppression bloquee si intervention referencee par un `ProcessIntervention` ou `DevisIntervention` non archive
7. Seed : 20 interventions du proto (`seed.js`) couvrant CHIRURGIE, MED_ESTH, SOIN
