# EP02-S04 — CRUD Frais supp par intervention

**Epic** : Parametrage Admin • **Priorite** : Must have • **Estimation** : 1.5h

> **Note 23/04** : le Parametrage est ouvert a tous les roles (plus ADMIN only). Voir [ADR-0006](../../architecture/decisions/0006-config-open-to-all-roles.md). Les mentions "ADMIN only / exclusif" dans cette story sont **revertes**.

## User story

En tant que **admin**, je veux **definir les frais supplementaires d'une intervention** (implants, kit, consommables) afin qu'ils soient **auto-ajoutes au devis technique**.

## Acceptance Criteria

1. Sous-section "Frais supplementaires" dans la page d'edition d'une intervention
2. CRUD des `InterventionFee` : label, defaultPrice, defaultQuantity, order, isActive
3. Drag & drop pour reordonner
4. Bouton "+ Ajouter un frais" avec form inline (label + prix + qty)
5. Apres ajout, les devis techniques futurs pour cette intervention auront ce frais **snapshote**
6. Les devis existants ne sont **pas** impactes (snapshot deja fige)
7. Seed : frais realistes pour les interventions cles (Implants Motiva, Kit Renuvion, Sondes VASER... cf. seed spec §10)

## Tests

- Test RBAC : ADMIN only (COMM 403, CHIR 403)
- Test snapshot : modif d'un frais catalogue → verifier qu'un devis existant garde l'ancien prix

## Notes techniques

- Table : `InterventionFee` (cf. data-model.md §2.7)
- Routes : `/api/interventions/:id/fees[/:feeId]`
- Permissions changees en v1.5 : ADMIN only (avant : tous)
- Prix en centimes
