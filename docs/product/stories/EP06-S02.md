# EP06-S02 — Upload + preview + telechargement documents

**Epic** : Documents • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **commercial**, je veux **uploader un document recu par mail/WhatsApp** (PDF ou image) et **le prevoir/telecharger** directement depuis le CRM, afin de **centraliser la collecte**.

## Acceptance Criteria

1. Bouton upload (Lucide Upload) sur chaque document en EN_ATTENTE → ouvre file picker
2. Formats accepts : `image/jpeg`, `image/png`, `application/pdf`
3. Taille max : 10 MB → 413 sinon
4. Anti path-traversal : rejet si `..` ou `/` dans le nom original → 400
5. Stockage local : `uploads/{tenantId}/{processId}/{uuid}.{ext}` (cf. stacks/backend.md §7)
6. Route `POST /api/processes/:id/documents/:dId/upload` (multipart)
7. Apres upload : `ProcessDocument.fileUrl = "{tenantId}/{processId}/{uuid}.{ext}"`, `status = RECU`, `receivedAt = now()`
8. Bouton Preview (Lucide Eye) :
   - Ouvre modal overlay avec image / iframe PDF
   - `GET /api/processes/:id/documents/:dId/preview` → rend inline (Content-Type image/pdf)
9. Bouton Download (Lucide Download) :
   - `GET /api/processes/:id/documents/:dId/download` → Content-Disposition attachment
   - Filename propose : `{processRef}-{documentName}.{ext}`
10. Bouton Supprimer (Lucide Trash2) → confirm dialog → supprime fichier + row

## Tests securite obligatoires

- [ ] Upload fichier > 10 MB → 413
- [ ] Upload fichier .exe → 400 (MIME non autorise)
- [ ] Upload avec nom `../../etc/passwd.pdf` → 400
- [ ] Tentative download d'un document d'un autre tenant → 404

## Notes techniques

- Lib : `multer` pour multipart
- Stockage path : `path.join(UPLOADS_DIR, tenantId, processId, uuid + ext)`
- Preview PDF via iframe ou object tag (pas de conversion)
