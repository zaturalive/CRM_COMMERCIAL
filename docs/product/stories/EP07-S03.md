## User story

En tant que **commercial**, je veux **voir la progression du paiement du solde** pour un process en Op programmee, afin de **relancer avant la date d'operation**.

## Acceptance Criteria

1. Composant `<PaymentProgressBar />` dans **Vue d'ensemble du Process Panel** :
   - Visible des le stage `OP_PROGRAMMEE`
   - Titre "Paiement du solde" + Lucide Banknote
2. Layout :
   - Grid 2 cols : Acompte (Lucide Check emerald si paye) + Solde en cours
   - Barre horizontale 8px, fond gris, remplissage emerald selon %
   - Ligne mono : `8 640 € / 17 280 €` + pourcentage
   - Solde restant en **rouge** (`#EF4444`) : "Solde restant : 8 640 €"
3. Warning si :
   - Solde < 100% ET date op < 15 jours
   - Affiche Lucide AlertTriangle amber + message "Operation dans X jours, solde incomplet"
4. Calcul : `paid = acompte (si paye) + Devis.soldePaidAmount`, `total = Devis.totalCached`
5. Integration aussi dans `<EventSheet />` (agenda)
6. Integration sur la carte pipeline (stage OP_PROGRAMMEE) : version compacte (juste %)

## Tests

- Test : devis 17 280 €, acompte paye 1 000 €, solde 7 640 → barre 50%
- Test warning : date op dans 10 jours + 50% → warning visible
- Test : solde 100% → barre pleine emerald, pas de warning
