## User story

En tant qu'**utilisateur de cabinet**, je veux **changer mon mot de passe depuis mon profil et y etre force au premier login**, afin de **ne pas rester sur le mot de passe initial fourni par l'editeur/l'admin**.

---

## Contexte

**Etat verifie (audit code 2026-06-01)** : **ABSENT** — aucune UI de changement de mot de passe, aucune route. Pire : le seed cree tous les comptes avec le mot de passe **"demo"** en dur (`apps/backend/prisma/seed.ts:185`). En l'etat, livrer a un client = lui donner un compte dont le mot de passe est public et qu'il ne peut pas changer. Le backlog §9 marque ce point "bloquant si le client doit changer le mdp demo initial".

---

## Acceptance Criteria

1. `POST /api/auth/change-password` (authentifie) body `{ currentPassword, newPassword }` : verifie l'ancien mot de passe, applique la regle de robustesse, set le nouveau hash bcrypt, met `mustChangePassword = false`.
2. Migration : `User.mustChangePassword Boolean @default(false)` (mis a `true` par le provisioning EP15-S01/S02 et par le seed pour les comptes initiaux).
3. **Gate force-change** : tant que `mustChangePassword = true`, l'utilisateur est redirige vers `/account/change-password` et ne peut pas acceder au reste de l'app (exemptions : logout, la page de change elle-meme).
4. Page `/account/change-password` : ancien + nouveau + confirmation, messages d'erreur clairs.
5. Le seed de demo conserve le comportement de demo, mais les comptes destines a un vrai cabinet partent avec `mustChangePassword = true`.
6. Regle de robustesse partagee avec EP15-S03 (longueur minimale, etc.) — factorisee.

---

## Tests de securite (obligatoires)

- [ ] Change-password avec ancien mot de passe correct → nouveau hash, `mustChangePassword=false`
- [ ] Ancien mot de passe incorrect → 401, pas de changement
- [ ] `mustChangePassword=true` → toute navigation redirige vers `/account/change-password`
- [ ] Nouveau mot de passe trop faible → 400
- [ ] Un user ne peut changer que **son** mot de passe (pas celui d'un autre)

Fichiers cibles : `apps/backend/tests/security/change-password.test.ts` + e2e force-change
