# EP04-S01 — Pipeline 5 colonnes avec CA par colonne

**Epic** : Pipeline & Process • **Priorite** : Must have • **Estimation** : 4h

## User story

En tant que **commercial**, je veux **voir tous mes process organises en 5 colonnes Kanban** afin de **suivre la progression commerciale et estimer le CA a chaque etape**.

## Acceptance Criteria

1. Page `/pipeline` accessible COMMERCIAL + ADMIN (redirect CHIR → dashboard)
2. Layout : 5 colonnes + 2 sections paralleles en dessous
3. 5 colonnes : Contact · Consultation · Post-consult · Confirmee · Op programmee
4. Chaque colonne :
   - Barre 4px couleur top (cf. design spec §1.3)
   - Titre + compteur `(N)`
   - Bloc CA : 3 lignes mono (Potentiel / Confirme / En attente)
   - Zone cartes, scroll interne
5. Drag & drop entre colonnes (@dnd-kit) avec validation transition (cf. EP04-S04 pour fil d'Ariane)
6. Endpoint `GET /api/pipeline` retourne processes groupes par stage (hors EFFECTUEE/ANNULEE)
7. Filtres : qualification (all / qualifie / non qualifie), intensite (slider 1-10), search nom patient
8. Bouton "+ Nouveau patient" ouvre form creation fiche client

## Tests

- Test : GET `/api/pipeline` sans JWT → 401
- Test : COMM tente drag vers CONSULTATION sans date consult → 422 avec raison
- Test : compteur et CA mis a jour apres drop

## Notes techniques

- Composant : `<KanbanBoard />` avec `<ProcessCard />` (EP04-S03)
- CA potentiel = somme devis non signes des process de la colonne
- CA confirme = somme devis signes + acomptes
- CA en attente = somme devis Follow-up
