# EP02-S02 — CRUD Options clinique catalogue

**Epic** : Parametrage Admin • **Priorite** : Must have • **Estimation** : 1.5h

> **Note 23/04** : le Parametrage est ouvert a tous les roles (plus ADMIN only). Voir [ADR-0006](../../architecture/decisions/0006-config-open-to-all-roles.md). Les mentions "ADMIN only / exclusif" dans cette story sont **revertes**.

## User story

En tant que **admin**, je veux **definir les options catalogue propres a chaque clinique** afin que **le commercial puisse les proposer au patient depuis le devis**.

## Acceptance Criteria

1. Sous-section "Options" dans la page de parametrage d'une clinique
2. CRUD des `CliniqueOption` : label, defaultPrice, defaultQuantity, order, isActive
3. Drag & drop pour reordonner (`order`)
4. Toggle `isActive` : les options inactives ne s'affichent pas dans le devis
5. Seed : 3 options par clinique (VASER, Chambre VIP, Bande compression... cf. proto seed.js)
6. Route `GET /api/cliniques/:id/options` accessible COMM+CHIR (utilisee par `<ClinicContextualOptions />`)

## Tests

- Test : POST sans `cliniqueId` → 400
- Test : GET liste filtree par `isActive=true` par defaut
