# EP04-S02 — Sections paralleles Non qualifie + Follow-up

**Epic** : Pipeline & Process • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **commercial**, je veux **voir les patients non qualifies et en follow-up dans des sections distinctes** avec la raison visible, afin de **garder la pipeline principale lisible**.

## Acceptance Criteria

1. Sous les 5 colonnes, 2 sections paralleles (meme largeur que la pipeline)
2. **Section Non qualifie** :
   - Border-left rouge 4px, fond `#FEF2F2`
   - Titre + compteur + CA potentiel perdu
   - Cartes avec label raison (Budget / Pas motive / Attentes / Autre)
   - Action : "Requalifier" (retour CONTACT) ou "Archiver"
3. **Section Follow-up** :
   - Border-left amber 4px, fond `#FFFBEB`
   - Titre + compteur + CA en attente
   - Cartes avec label raison (TEMPS / ARGENT / HESITATION / AUTRE)
   - Action : "Retour Post-consult" ou "Archiver"
4. Transition vers ces sections = dialog obligatoire pour saisir la raison
5. Endpoints : `PATCH /api/processes/:id/non-qualifie`, `PATCH /api/processes/:id/followup`, `PATCH /api/processes/:id/requalifier`, `PATCH /api/processes/:id/archive`

## Tests

- Test : PATCH non-qualifie sans raison → 400
- Test : PATCH followup avec `followupReason = TEMPS` → 200, process dans la section

## Notes techniques

- Dialog shadcn `<Dialog />` avec `<Select />` des raisons + textarea "Autre"
- Les cartes dans ces sections sont **non draggable** (actions par boutons uniquement)
