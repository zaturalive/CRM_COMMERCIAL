**Epic** : Fiche Client • **Priorite** : Must have • **Estimation** : 1h

## User story

En tant que **commercial**, je veux **voir d'un coup d'oeil les devis signes et non signes d'un client** afin de **savoir sur quoi relancer**.

## Acceptance Criteria

1. Colonne droite (30%) de la page `/clients/[id]` titree "Devis" (Lucide FileText)
2. Sous-section **Devis signes** (badge Lucide CheckCircle emerald) :
   - Liste compacte : ref + montant mono + date signature
   - Clic → ouvre le devis
3. Sous-section **Devis non signes** (badge Lucide FileMinus gris) :
   - Liste compacte : ref + montant mono + date creation
   - Bouton "Relancer" (Lucide Bell) → toast "Relance envoyee" (MVP simulee)
4. Tri : plus recent en haut
5. Endpoint `GET /api/clients/:id/devis` groupe par statut

## Tests

- Test : client avec 2 devis signes + 1 non signe → 2 + 1 dans le panneau
- Test clic : navigation `/devis/[id]`

## Notes techniques

- Utilise les `Devis.firstSignedAt` pour separer signes/non signes
- Relance en V1 : mail + WhatsApp. Au MVP : toast seulement
