## User story

En tant que **commercial**, je veux **ajouter une option personnalisee** (qui n'existe pas au catalogue) directement sur un devis, et **voir le total se recalculer en temps reel**, afin de **personnaliser le devis sans passer par le parametrage**.

## Acceptance Criteria

### Options a la volee

1. Section "Options personnalisees" en bas du devis commercial
2. Bouton "+ Ajouter une option personnalisee" → form inline : label + prix mono + quantite
3. Par ligne : `<CustomOptionRow />` editable + Lucide X pour supprimer
4. Validation : `price >= 0`, `quantity >= 1`
5. Endpoints : `POST/PATCH/DELETE /api/devis/:id/custom-options`

### Calcul temps reel

6. `<DevisTotalSticky />` en position sticky bas-droite :
   - Honoraires praticien (libelle de facturation — ADR-0002)
   - Frais interventions (sum des `DevisInterventionFee.price * qty` isIncluded)
   - Frais clinique (bloc + anesth + sejour par groupe)
   - Options catalogue
   - Options personnalisees
   - Separateur
   - TOTAL GENERAL (DM Sans 28px, accent, mono + CopyButton)
7. Chaque modification (save debounced 300ms) appelle `GET /api/devis/:id/total`
8. Animation bounce scale 1.05 → 1 sur le total apres recalc
