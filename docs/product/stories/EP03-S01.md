## User story

En tant que **commercial**, je veux **creer, rechercher et modifier une fiche client** afin de **centraliser les donnees pereennes du patient**.

## Acceptance Criteria

1. Page `/clients` : liste paginee + recherche (nom, prenom, telephone, email)
2. Bouton "+ Nouveau client" → form modal : nom, prenom, telephone (obligatoire), email, ville, adresse, source, doctolibUrl
3. Dedup sur `(tenantId, phone)` : si existant, proposer "Importer" (reutiliser la fiche)
4. Validation telephone : format francais `^0[1-9]\d{8}$`
5. Validation email : format RFC 5322
6. Validation source : enum `SourceAcquisition`
7. Edition d'une fiche depuis la liste
8. Suppression bloquee si process actif (409) — suppression ADMIN only
9. Seed : 15 clients fictifs du proto `seed.js`

## Tests

- Test validation : telephone non francais → 400
