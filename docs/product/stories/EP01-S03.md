## User story

En tant que **utilisateur de la demo**, je veux **basculer entre les roles Admin / Commercial / Chirurgien** afin de **voir la sidebar s'adapter et demontrer l'isolation des droits**.

## Acceptance Criteria

1. Sidebar fixe 240px, fond `var(--sidebar-bg)`, texte blanc
2. Item actif : fond `var(--accent)` + radius 8px
3. Items visibles selon role :
   - ADMIN : Dashboard, Pipeline, Clients, Agenda, **Parametrage**
   - COMMERCIAL : Dashboard, Pipeline, Clients, Agenda (pas de Parametrage)
   - CHIRURGIEN : Dashboard, Clients, Agenda (pas de Pipeline, pas de Parametrage)
4. Placeholders "Coming Soon" avec badges V1/V1.1/V1.2 : Paiements, Agent IA, Messages, Signatures
5. Footer sidebar : avatar + nom + role en 11px gris + dropdown `<RoleSwitcher />`
6. `<RoleSwitcher />` (demo only) : bascule le role dans le JWT via POST `/api/demo/switch-role`, refresh page
7. En production (`NODE_ENV=production`), la route demo renvoie 404 et le switcher est masque
8. Navigation clavier (tab + enter) fonctionne sur tous les items

## Tests

- Test switcher : bascule COMMERCIAL → ADMIN → item Parametrage apparait
- Test guard : COMMERCIAL visite `/config/cliniques` directement → redirect `/dashboard`
- Test securite : POST `/api/demo/switch-role` en `NODE_ENV=production` → 404
