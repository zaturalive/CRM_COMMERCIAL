## User story

En tant que **commercial**, je veux **voir l'essentiel de chaque process sur sa carte** afin de **prendre les bonnes decisions sans ouvrir le panel**.

## Acceptance Criteria

Chaque ProcessCard contient :

1. **Haut gauche** : nom patient bold 14px + bouton `<CopyButton />` (hover only, 0.45 → 1 opacity)
2. **Haut droite** : badge qualification (Lucide Check / X) + intensite `8/10` mono
3. **Sous nom** : intervention principale (13px gris)
4. **Badge consultation** (si colonne Consultation) :
   - Aujourd'hui (emerald) / A venir (bleu) / Passee (gris)
5. **Label raison** (si section Non qualifie ou Follow-up)
6. **Bas** :
   - Date cle (Lucide Calendar + mono)
   - Tags : signe / paye (Lucide Check) / devis en cours (Lucide Clock)
   - Montant (bold mono + Copier)
7. **Action bouton Archiver** (Lucide Archive) visible dans Follow-up / Non qualifie

Structure coherente avec design spec §5.3.

## Tests
