# EP08-S01 — Dashboard 4 KPIs + chart CA

**Epic** : Dashboard • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **commercial ou chirurgien**, je veux **un dashboard avec les chiffres cles du cabinet** afin de **suivre ma performance en temps reel**.

## Acceptance Criteria

1. Page `/dashboard` accessible COMM + CHIR + ADMIN
2. **4 KPI cards** (grid 4 cols) :
   - Total patients (Lucide Users) : count `Client` du tenant
   - Consults du mois (Lucide Calendar) : count Process avec `consultationDate` dans le mois
   - CA du mois (Lucide Euro) : somme des Devis signes + paies ce mois (mono)
   - Taux de conversion (Lucide TrendingUp) : `(Confirmee + OP_PROGRAMMEE + EFFECTUEE) / (CONTACT + ... total) * 100`
3. **CA Chart** (60% gauche) :
   - Toggle periode : Semaine / Mois / Annee
   - Line chart (chart lib au choix : Recharts ou visx)
   - Endpoint `GET /api/dashboard/ca?period=week|month|year` retourne serie temporelle
4. **Previsionnel** (40% droite) : voir EP08-S02
5. **CA en attente Follow-up** (100% bas, fond amber) : voir EP08-S02

## Tests

- Test : seed avec 5 devis ce mois → CA du mois = somme attendue
- Test : taux conversion avec 3 confirmes sur 10 process actifs → 30%

## Notes techniques

- Endpoints : `/api/dashboard/kpis`, `/api/dashboard/ca`, `/api/dashboard/previsionnel`, `/api/dashboard/ca-en-attente`
- Prefer Recharts (plus leger) — visx seulement si chart complexe
