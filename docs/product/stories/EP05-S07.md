# EP05-S07 — PDF Puppeteer + Copier texte + Envoyer grise + signature simulee

> **HDS-CHECK** (2026-05-18) — Verdict : `OK avec rename`
> Periode : NON-HDS (cf. ADR-0008 du repo source)
> Mots-cles BLOCKED detectes : aucun
> Mots-cles SUSPECT detectes : "patient" (preferer "client" — P4), "intervention" (preferer "prestation" — P4), "clinique" / "anesthesie" / "ambulatoire" (OK contexte logistique).
> **MAJ 2026-05-20** : "chirurgien" caduc (ADR-0002 retire le role). Signature PDF : libelle "praticien" (facturation).
> Action : rename requis
> Justification : generation PDF + texte multi-lignes du devis. Le template texte recapitule les lignes commerciales (intervention/frais/clinique/sejour/options/total) sans contenu medical.

**Epic** : Devis • **Priorite** : Must have • **Estimation** : 4h

## User story

En tant que **commercial**, je veux **telecharger le PDF du devis** et **copier le devis en texte pour mail/SMS**, avec un **bouton Envoyer grise prevoyant la V1**, afin de **transmettre le devis au patient via le canal qu'il prefere**.

## Acceptance Criteria

### Header devis

1. Reference mono + CopyButton + DevisStatus badge
2. Bouton `Copier le devis complet en texte` (Lucide Clipboard)
3. Bouton `Telecharger PDF` (Lucide Download) — actif
4. Bouton `Envoyer` (Lucide Send) **grise** avec badge V1
   - Tooltip : "Disponible en V1 — envoi du lien de signature par mail et WhatsApp"
   - Backend `POST /api/devis/:id/send` renvoie **501 Not Implemented**
5. Bouton "Marquer signe" (simulation MVP) → `POST /api/devis/:id/sign`

### PDF

6. `GET /api/devis/:id/pdf` genere un PDF via Puppeteer :
   - Template HTML inline (CSS grid, fonts chargees)
   - Headers : logo + cabinet + reference + date + patient
   - Body : interventions + frais supp + clinique + sejour + options + custom options
   - Footer : total general + signature simulee (praticien + client placeholder — ADR-0002)
7. Fichier nomme `DEV-YYYY-XXXX.pdf`
8. Content-Type : `application/pdf`, Content-Disposition : `attachment`

### Texte plain

9. `GET /api/devis/:id/as-text` retourne une version texte multi-lignes :
```
Devis DEV-2026-0042 - Dr Delobaux
Patient : Sophie Marchand

Interventions :
  - Liposuccion 360 : 6 500 €
    + Kit canules VASER : 380 €
  - Abdominoplastie : 6 200 €

Frais clinique (ALPHAND, 15/05/2026) :
  - Bloc + anesthesie : 1 470 €
  - Ambulatoire : 350 €

Options :
  - VASER haute definition : 800 €

TOTAL : 15 700 €
```
10. Bouton "Copier le devis complet en texte" copie le resultat dans le presse-papier

### Signature simulee

11. `POST /api/devis/:id/sign` : marque `firstSignedAt = now()` et `DevisStatus = SIGNE`
12. En V1 : Yousign + double signature J+15 (out of scope)

## Tests

- Test PDF : GET `/api/devis/:id/pdf` renvoie bytes > 10 KB et mime correct
- Test text : format conforme, montants en €
- Test securite : COMM peut signer, CHIR peut signer, ADMIN peut signer
