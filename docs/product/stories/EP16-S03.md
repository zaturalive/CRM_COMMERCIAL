## User story

En tant qu'**utilisateur commercial**, je veux **une petite previsualisation a droite du devis maker qui se met a jour en temps reel**, afin de **voir le rendu du devis pendant que je le remplis, sans avoir a generer le PDF.**

---

## Contexte

**Demande utilisateur (2026-06-01)** : "une petite previsualisation a la droite du devis maker". Recoupe le retour commercial (`RETOUR-COMMERCIAL-2026-05-27.md` §2.2 : "Vue PDF en live") — etait classe V1.1, remonte dans la vague pre-prod.

**Nuance scope** : c'est une **petite** previsualisation (apercu live), pas la refonte complete (brouillon + wizard restent V1.1). Distinct de EP16-S01 qui produit le PDF telechargeable.

**Etat technique** : le DevisBuilder existe (`apps/frontend/src/components/devis/DevisBuilder.tsx`). On ajoute un panneau d'apercu a cote de l'editeur.

---

## Acceptance Criteria

1. Layout du DevisBuilder en deux zones : editeur a gauche, panneau de previsualisation a droite.
2. Le panneau se met a jour en temps reel quand le commercial modifie le devis (prestations, montants, remise EP16-S02).
3. L'apercu reflete les memes calculs que le PDF final (EP16-S01) : reutilisation de la **fonction de calcul unique** (coherence apercu vs PDF vs KPIs).
4. Rendu leger : apercu HTML/React, sans regenerer le PDF Puppeteer a chaque frappe (perf).
5. Responsive : le panneau se replie/masque sur petit ecran.
6. Aucun element medical dans l'apercu (garde-fou EP16 : pas de consentement medical, frais anesthesiste, etc.).
7. Optionnel : bouton "Voir le PDF complet" qui declenche la generation reelle (EP16-S01).

---

## Tests (obligatoires)

- [ ] Modifier une prestation / la remise → l'apercu se met a jour, totaux corrects (apres remise)
- [ ] Apercu coherent avec le PDF genere (memes montants)
- [ ] Pas de lag perceptible a la frappe (rendu leger, pas de regeneration PDF a chaque keystroke)
- [ ] Petit ecran → panneau repliable, editeur reste utilisable
- [ ] Aucun champ medical rendu dans l'apercu

Fichiers cibles : `apps/frontend/tests/e2e/devis-preview.spec.ts` + unit calcul partage

---

## Notes techniques

- **Calcul partage** : la fonction de calcul total (avec remise EP16-S02) est centralisee et consommee par l'editeur, l'apercu, le PDF et les KPIs — une seule source de verite.
- **Rendu** : composant React leger qui mappe l'etat du devis ; le PDF Puppeteer reste reserve a la generation finale (EP16-S01).
- **Layout** : split-pane responsive ; sur mobile, l'apercu passe en onglet ou en tiroir.
