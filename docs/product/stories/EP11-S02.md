# EP11-S02 — Badge engagement sur fiche client + carte process

**Epic** : Click tracking demo • **Priorite** : Must have • **Estimation** : 2h

## User story

En tant que **commercial**, je veux **voir d'un coup d'oeil l'engagement d'un patient** (combien de fois il a cliqué/vu/ouvert) sur sa fiche, sa carte de pipeline, et la page follow-up, afin de **prioriser les relances vers les patients les plus engages**.

## Acceptance Criteria

### API enrichissement

1. La reponse `GET /api/processes/:id` inclut un champ `engagement` :
   ```json
   {
     "totalEvents": 5,
     "byType": { "CLICK_LINK": 3, "VIEW_VIDEO": 2 },
     "lastEventAt": "2026-04-25T..."
   }
   ```
2. La reponse `GET /api/pipeline` enrichit chaque process avec un champ resume :
   ```json
   { "engagementCount": 5, "engagementLastAt": "..." }
   ```
3. La reponse `GET /api/follow-up` enrichit de meme
4. Performance : aggregation via Prisma `groupBy` sur `TrackingEvent.eventType` filtre par `processId` (un seul roundtrip DB par requete liste)

### UI carte process (pipeline + follow-up)

5. Nouveau badge sur `ProcessCard` :
   - Icone `Activity` Lucide + `engagementCount`
   - Couleur degradee selon count : 0 = gris, 1-2 = neutre, 3-5 = bleu, 6+ = vert
   - Tooltip au hover : "X events — dernier: Y jours"
   - Position : a cote des badges existants (devis, documents)

### UI fiche client `/clients/[id]`

6. Nouvelle section "Engagement" dans la fiche :
   - Resume : "X events au total — dernier: Y"
   - Timeline chronologique des events (reuse pattern de la timeline EP09-S03)
   - Filtres : par `eventType`, par `processId`
   - Bouton "+ Ajouter un event manuel" → dialog modal :
     - Select `eventType` + `targetKind`
     - Champ `targetLabel` (texte libre)
     - Champ `targetUrl` optionnel
     - Select `processId` optionnel (sinon event au niveau client)
     - Champ `note`
     - Bouton "Enregistrer"
   - L'event cree apparait immediatement dans la timeline (optimistic)

### UI ProcessPanel

7. Onglet "Suivi" du ProcessPanel (cree en EP09-S03) etendu :
   - Section "Engagement" en bas qui reprend la timeline filtree par ce process
   - Bouton rapide "Marquer comme clique" → cree un event `CLICK_LINK` `targetKind=CUSTOM` avec `note` libre

## Tests

- Test integration : `GET /api/processes/:id` retourne `engagement` agrege
- Test integration : carte process en pipeline affiche le bon `engagementCount`
- Test E2E : ajouter un event manuel → reload page → event visible dans timeline + count incremente
- Test unit : la fonction `aggregateEngagement(processId)` retourne le bon shape

## Notes techniques

- Aggregation : `prisma.trackingEvent.groupBy({ by: ['eventType'], where: { processId }, _count: true })`
- Le badge sur ProcessCard reuse le shadcn `Badge` (deja utilise pour le devis/documents)
- La timeline reuse le pattern de EP09-S03 (markers colores)
