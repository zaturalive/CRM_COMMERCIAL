# EP06-S03 — Badge documents X/Y + integration vue d'ensemble

**Epic** : Documents • **Priorite** : Must have • **Estimation** : 1h

## User story

En tant que **commercial**, je veux **voir en un coup d'oeil combien de documents sont recus** sur le process, afin de **savoir quand passer en Op programmee**.

## Acceptance Criteria

1. Composant `<DocumentProgressBadge />` :
   - Carte compacte avec Lucide FolderCheck + "Documents : X/Y"
   - Fond `#FEF3C7` (amber) si X < Y
   - Fond `#D1FAE5` (emerald) si X = Y
2. Visible dans **Vue d'ensemble du Process Panel** :
   - Des le stage `CONFIRMEE`
   - Clic sur le badge → bascule sur l'onglet Documents
3. Compteur : `X` = docs avec statut `RECU` ou `VALIDE`, `Y` = total docs
4. Badge temps reel : actualise apres modif statut (via React Query invalidate)
5. Visible aussi sur les cartes pipeline (stage CONFIRMEE ou OP_PROGRAMMEE) en version compact
6. Visible dans l'historique process de la Fiche Client

## Tests

- Test : 3 docs RECU + 3 EN_ATTENTE → badge "3/6" amber
- Test : tous VALIDE → badge "6/6" emerald
- Test clic : navigation vers onglet Documents

## Notes techniques

- Compute cote backend (dans `GET /api/processes/:id`) pour eviter N+1
- React Query invalidate sur `processes/:id` apres PATCH document
