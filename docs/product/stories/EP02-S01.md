## User story

En tant que **admin**, je veux **configurer les cliniques partenaires avec leurs tarifs** afin que **les devis calculent automatiquement les frais bloc/anesthesie selon la duree**.

## Acceptance Criteria

1. Page `/config/cliniques` accessible ADMIN uniquement (401 / redirect sinon)
2. Liste des cliniques du tenant avec search + bouton "+ Nouvelle clinique"
3. Form : nom, ville, telephone, frais ambulatoire, frais hospitalisation/nuit (nullable)
4. Grille tarifaire par clinique : CRUD des `CliniqueTarif` (dureeMin, dureeMax, fraisBloc, fraisAnesthesie)
5. Validation : intervalles `[dureeMin, dureeMax]` ne se chevauchent pas pour une meme clinique
6. Bouton "Dupliquer la grille" pour copier depuis une autre clinique
7. Suppression bloquee si clinique referencee par une `DevisIntervention` non archivee (409 Conflict + message)
8. Seed : 2 cliniques (CEPE, ALPHAND) avec leurs grilles de `donnees-configuration-seed.md` §1

## Tests
