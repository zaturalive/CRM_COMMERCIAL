## User story

En tant qu'**utilisateur** (COMMERCIAL ou ADMIN — ADR-0002 retire CHIRURGIEN), je veux **ouvrir un event dans un panneau lateral** pour cocher les interventions effectuees et reprogrammer si besoin, afin de **finaliser le suivi en fin de journee**.

## Acceptance Criteria

### EventSheet

1. Clic event → `<EventSheet />` slide-in 200ms depuis la droite (480px)
2. Header :
   - Badge type (ex "Operation · J-15" fond amber)
   - Bouton X
   - Nom patient DM Sans 22px 700
   - Ligne date/heure (Lucide Clock + mono)
   - Chip clinique "ALPHAND — Lyon · 1 nuit" (Lucide MapPin)
3. Body avec sections (gap 20px) :
   - **Interventions a effectuer** "0 / 2" — cards avec checkbox ronde 22px
   - **Paiement** — carte degrade selon statut, progress bar
   - **Devis (recap)** — lignes mono + total + Copier
   - **Documents pre-op** — pastille statut par document
   - **Patient** — tel, email, source + CopyButton
4. Footer :
   - Primary `Ouvrir la fiche process` (Lucide ArrowUpRight) → navigate + open Process Panel
   - Secondary `Reprogrammer` (Lucide CalendarClock)

### Cocher intervention

5. Click checkbox → `PATCH /api/devis-interventions/:id/done` avec `{ isDone: true }`
6. Animation : checkbox scale 1.2 → 1 (emerald) + strikethrough 150ms
7. Hook backend `checkAutoArchive(processId)` appele (EP04-S06)
8. Si toutes cochees + solde 100% → toast "Process archive en Effectuee" + event grise barre

### Reprogrammation

9. Drag event (tous roles authentifies — ADR-0002 retire le gating CHIRURGIEN) : opacity 0.8 grab, drop → confirm si paye
10. Endpoint `PATCH /api/devis-stays/:id/date` :
    - Met a jour `DevisStay.date`
    - Cascade : toutes les `DevisIntervention.dateIntervention` du sejour
11. Consultation : drag → `PATCH /api/processes/:id/consultation-date`
