## User story

En tant que **admin**, je veux **associer des documents administratifs et financiers a une prestation** (soit via un label existant, soit en creant un nouveau label a la volee) afin qu'ils **soient auto-ajoutes a la checklist** quand le client choisit cette prestation.

## Acceptance Criteria

1. Page `/config/document-labels` : CRUD global des `DocumentLabel` (nom, description, isRequiredByDefault)
2. Liste avec compteur "utilise dans X prestations"
3. Suppression bloquee si label utilise par un `ProcessDocument` sur un process non archive (409)
4. Sous-section "Documents a demander" dans l'edition d'une prestation :
   - Liste compacte des labels associes : nom, toggle obligatoire, drag order, X desassocier
   - Bouton "+ Ajouter un document associe" → ouvre `<DocumentLabelPicker />`
5. `<DocumentLabelPicker />` (modal) avec 2 options :
   - **Choisir un label existant** : recherche + liste, clic = associe
   - **Creer un nouveau label** : form inline (nom + description + isRequiredByDefault), clic "Creer et associer" = cree + associe atomiquement (transaction)
6. Route `POST /api/interventions/:id/document-labels` avec payload union (Zod) : `{ documentLabelId }` OU `{ newLabel: { name, description, isRequiredByDefault } }`
7. Seed : 8 labels commerciaux (Carte d'identite, Justificatif de domicile, RIB, Mutuelle / tiers payant, Attestation employeur, Devis signe, CGV signees, Plan de financement)
8. Seed : associations par defaut sur chaque prestation (Carte d'identite, RIB, Devis signe, CGV signees pour tous les types ; Mutuelle et Attestation employeur en optionnel)
